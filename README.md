# Mr. Sandwich — Devigarh

Modern vegetarian café website for **Mr. Sandwich** (Devigarh, Patiala). Built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Menu data

Edit `scripts/build-menu.mjs` and run `node scripts/build-menu.mjs` to regenerate `src/data/menu.ts`, or edit `src/data/menu.ts` directly.

Business details live in `src/data/restaurant.ts`.

## Development

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server

Built with [BrainDaemon](https://braindaemon.com)
